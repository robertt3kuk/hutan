## Items (in commit order)
1. `hutan proxy`: bytes-only bridge between stdin/stdout and the local daemon socket (flush per read, no PTY, autostart the daemon on that host like any client, bounded buffers); exits when either side closes.
2. Client `Endpoint::Ssh { host profile }`: spawns the system `ssh` (`ssh -T -o BatchMode=yes … hutan proxy`, honouring the user's `~/.ssh/config`, ControlMaster when configured) and runs the protocol over its stdio; supervised (exit → reconnect with `hello.resume`); never stores passwords or keys.
3. `[[host]]` profiles in the client settings (`name`, `ssh` destination, optional `hutan` path on the host); `hutan --host NAME <command>` for every CLI command; `hutan host list|add|remove|test`.
4. Managed local forward for third-party tools: `hutan host forward NAME` runs `ssh -N -L <local sock>:<remote sock>` with `StreamLocalBindUnlink=yes` + `ExitOnForwardFailure=yes`.
5. Docs: `docs/remote.md` (new; add to AGENTS.md document map) — setup, security (SSH is the auth; no listener), limits; ADR 0022 status "R-2 implemented".
(Desktop multi-host UI is R-3 — out of scope.)
