## Contract

### Commands
- `hutan new [--ws ID] [--cwd PATH] [--title T] [--env K=V]… [--attach] [-- ARGV…]` → `session.create`; prints `session <id> terminal <tid>` (or JSON). No ARGV = login shell. `--cwd` defaults to the current directory. `--attach` attaches immediately.
- `hutan ls [--ws ID] [--json]` → table: ID, TERMINAL, STATE (with exit code), TITLE, CWD, AGE.
- `hutan attach <target>` where target = session id, unique id prefix (≥ 4 chars), terminal id (`t:7`), or exact title. Behavior:
  1. raw mode via the `host` guard (restored on every exit path, including panic and SIGTERM/SIGHUP);
  2. `terminal.attach` with the host size; render the snapshot with `HostRenderer::enter` + `apply_snapshot`; for every subsequent render write the bytes to stdout, flush, **then** send `terminal.ack` for that frame number;
  3. stdin bytes → `DetachDetector` → `send_input` (raw bytes, unmodified: the host terminal already encodes keys per the modes the renderer mirrored);
  4. SIGWINCH → `terminal.resize` with the new host size;
  5. detach on ctrl+\ then d: `terminal.detach`, `HostRenderer::leave`, restore the terminal, print `[detached from <id>]`, exit 0;
  6. session exits → leave, print `[session exited with code N]`, exit 0; daemon disconnects → leave, print an error, exit 3;
  7. `session.updated` with a new terminal id (restart) → re-attach transparently.
- `hutan send <target> <text> [--enter]`, `hutan stop <target>`, `hutan restart <target>`, `hutan rename <target> <title>`, `hutan history <target> [--lines N]` (plain text, oldest first).

### Bench (M1.7)
`cargo run --release -p hutan-daemon --example flood` (in-process daemon on a temp `HUTAN_HOME`): session runs `sh -c 'head -c 150000000 /dev/urandom | base64; exec cat'` (≈200 MB output); two clients attached — one acks every render, one never acks. Report: wall time until the output finished (watch `terminal.history` length or a sentinel line), renders received by the acking client, daemon `daemon.status` p50/p99 latency sampled every 50 ms during the flood, peak RSS (`getrusage` self; isolated `unsafe` with `// SAFETY:` in the example only). Print one summary line; record numbers in the report.
