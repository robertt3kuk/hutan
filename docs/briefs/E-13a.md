- **⌘P palette** (Zed base): one list, *Files* first (fuzzy over `fs.find` in the active project's root, ranked by path-segment match + recency; recent files at the top with an empty query), then *Sessions* (today's jump entries). `path:line[:col]` in the query opens at that position. Return opens in the focused pane, ⌘Return in a split. ⌘J keeps the jump palette in the Hutan base. Stale entries (removed projects, e.g. a folder opened by mistake then replaced) are not offered.
