## Scope
- **Document sync**: an open file tab opens/changes/saves/closes its daemon mirror through `doc.*` (debounced; only when the capability `doc.sync` is present and the folder has a server configured — no traffic otherwise).
- **Trust prompt**: when a server is `untrusted` with `trust_pending` for the active file's folder, a quiet inline bar in the editor: "Language server for Rust runs build scripts and proc macros from this folder. Trust <folder>?" with *Trust* / *Not now*; *Trust* calls `lsp.trust` (user-only). `not_installed` shows the install command once (copyable), never a download.
- **Diagnostics**: underline styles by severity (error wavy, warning dotted, info/hint straight thin) plus a gutter glyph whose *shape* differs by severity; message on hover and as an inline end-of-line hint for the caret line only (not every line — Helix #1462); anchors keep them on the right text while editing until the next publish; `]d` / `[d` (Vim) and F8 / ⇧F8 (non-Vim) jump.
- **Problems panel** (registered panel, own settings namespace): grouped by file, severity filter, click/Return opens at position; empty state text-only.
- **Hover**: on mouse rest (≥ 500 ms) and `K` (Vim) / ⌘K ⌘I (Zed base) → popover with markdown rendered as plain styled text (code blocks monospaced); dismiss on move/Escape.
- **Go to definition**: ⌘-click and `gd` (Vim), F12 (non-Vim) → opens across files, pushes the jumplist (`⌃O` returns).
- **Status item** `editor.diagnostics` (counts with glyph shapes, click → Problems) and the server state (`starting`, `indexing`, `ready`, `failed` with reason in a tooltip).
- Docs: `docs/editor.md`, `docs/design.md` (diagnostics styles, Problems panel, trust bar).
