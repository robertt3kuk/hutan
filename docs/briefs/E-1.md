## Scope
New crate `crates/buffer` (package `hutan-buffer`, GPUI-free, no tokio requirement), registered in the workspace; new dependencies go into root `[workspace.dependencies]` and must pass `cargo deny` (MIT/Apache/BSD/MPL as `deny.toml` allows).
1. **Rope choice first**: micro-bench `crop` vs `ropey` (2.x if released, else 1.x) for open (1 MB, 10 MB), random insert/delete, line↔offset, UTF-16 conversion; commit the bench (`benches/` or an `xtask`-free `#[ignore]` timing test) and pick one in the first commit with the numbers in the commit message and `docs/perf.md` (new "Editor" rows). The spike's prior is `crop`.
2. `Buffer`: text, line endings (LF/CRLF detected, preserved), BOM, UTF-8 validation with binary detection (refuse with a typed error), version counter.
3. `Transaction` (ordered edits on byte ranges, composable), `apply`, inverse; **undo tree with groups** (undo/redo of whole groups; a group = one user action), time/size-bounded history (bounded per AGENTS.md).
4. `Selections` (multi-cursor, primary, merge overlapping) and `Anchor`s that map through transactions (bias left/right).
5. Coordinate conversions: byte ↔ char ↔ (line, column) ↔ **UTF-16** (needed by GPUI's `EntityInputHandler` and LSP position encodings).
6. `apply_external(new_text)`: minimal diff (`similar`) applied as one transaction so anchors in unchanged regions stay put (for agent edits arriving from disk).
7. Search over the rope (literal + regex via `regex-cursor` or equivalent), bounded results.
8. Public API documented in rustdoc; `docs/architecture.md` crate list updated.

## Contract
- GPUI-free, no I/O beyond `from_reader`-style constructors on caller-provided bytes; no global state.
- All offsets in the public API are byte offsets unless the function name says otherwise (`*_utf16`, `*_char`).
- No `unwrap/expect` outside tests (clippy enforces).

## Acceptance
- Property tests (`proptest`): random edit sequences equal a `String` model; undo∘redo = identity; anchors stay on the same text through edits; `apply_external` leaves anchors in unchanged regions in place; UTF-16 ↔ byte round-trips incl. emoji, combining marks and CRLF.
- Bench numbers recorded in `docs/perf.md` (machine, build profile, method).
- Unit tests live in the crate; integration tests, if any, use the BLD-1 layout (`tests/it/main.rs`).
- `just check` green (it queues on the machine-wide gate lock; iterate with `cargo nextest run -p hutan-buffer`). One commit on `slice/E-1` ending `(E-1)`.
