## Scope
New crate `crates/syntax` (package `hutan-syntax`): language registry; grammars compiled in behind cargo features (Rust, TypeScript/TSX, JavaScript, Python, Go, JSON, TOML, YAML, Markdown, Bash, HTML/CSS, C/C++ — drop any whose grammar crate is unmaintained or license-incompatible and say so); incremental parse with edits, on a background thread with cancellation and version tags (a stale tree never blocks; a newer version cancels the old parse); `highlights(range)` → spans of capture names mapped to a small token table (`syntax.keyword`, `syntax.string`, … to be themed by E-4); `node_at`, expand/shrink selection, folds, bracket match, indent hints; query files vendored with attribution and license notices.

## Acceptance
- Highlight fixtures per language (golden spans for a snippet).
- Incremental edit equals a fresh parse over 200 random edits.
- Cancellation: a newer version cancels an in-flight parse; no blocking on a stale tree.
- 1 MB Rust file: parse and range-query timings recorded in `docs/perf.md`; binary-size delta of the grammars recorded.
