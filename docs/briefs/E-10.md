## Lessons that are part of the spec (from the evidence)
1. Never write an agent's change silently over a dirty buffer: a clean buffer reloads as one undo step with the caret kept; a dirty one shows the existing conflict bar and never loses text.
2. **Per-hunk Reject from day one**, scoped to the current agent turn's hunks (not "restore file"); Reject is undoable and never deletes a file.
3. A **pending ledger** of the turn's agent hunks per file that survives switching chats, models and a restart (derive from the CK-2 start tree when checkpoints are on, else from the turn's `FileDiff`s), reconciled after terminal/Bash writes (`fs.changed` with origin `external`/`agent{session}`).
4. Decorations must match what is on disk; throttle the live diff for large or minified files and offer an off switch (`editor.agent_highlight`).
5. Default is direct writes + ledger (no approve-before-write gate in the editor).
