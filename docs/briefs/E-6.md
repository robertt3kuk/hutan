## Scope
`crates/code_view`, `crates/desktop` (file item wiring, actions, keymap contexts, status items), docs (`docs/editor.md`, `docs/design.md` § editor).
1. Caret and selections (multi-cursor: ⌘D next occurrence, ⌥-click add caret, column select), keyboard navigation (word/line/page/document), `EntityInputHandler` with UTF-16 offsets, marked text (IME) and `bounds_for_range` for the candidate window.
2. Edits through `buffer` transactions: insert/delete, indent/outdent, auto-indent and auto-pairs from `syntax`, comment toggle, duplicate/move line, clipboard (cut/copy/paste, multi-caret aware), undo/redo (⌘Z/⇧⌘Z) by groups; incremental reparse after each edit (no full reparse).
3. Save (⌘S) via `fs.write` with the open version as precondition: conflict when the file changed on disk → non-modal bar *Reload · Keep mine (overwrite) · Show diff*, never a silent overwrite; dirty marker on the tab and *Save before closing?* on close; optional `editor.autosave = "off" | "on_focus_change" | "after_delay"`; CRLF/BOM preserved on write.
4. External changes while clean: reload via `apply_external` keeping cursor and undo coherent (full agent-aware UX is E-10; here only the clean-buffer reload and the dirty conflict bar).
5. In-file replace (find bar from E-5 gains Replace / Replace all as one undo step).
6. Vim stays off in the editor in this slice (E-8 wires it); `editor.vim_mode` must not break typing.
