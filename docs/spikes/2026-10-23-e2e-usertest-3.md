## New findings

**Major**

**Minor**
- **N9 Daemon menu items all disabled to the AX driver** (`invoke_menu` "path segment 1 is disabled" for Stop/Start/Restart/Status…/Keep Running, while the daemon ran and a chat session was live). The menu lists "Start with Empty Data…" and "Stop the Stuck Daemon…" while the daemon is healthy. [INFERENCE] items may be enabled only after the menu opens (AppKit validation) — untested by hand; please verify a click works. (menu probe)
- **N1 "Start Daemon at Login (not found)" / Setup Background step: "The launch agent is missing from Hutan.app."** although `Contents/Library/LaunchAgents/dev.hutan.daemon.plist` is in the bundle. [INFERENCE] `SMAppService.status` returns notFound for an ad-hoc-signed bundle outside /Applications; the text blames the bundle. Verify in a bundle in /Applications before release; if it also happens there, start-at-login is unusable. (08, Daemon menu)
- **N4 Read-only file gives no cue**: no lock/“read-only” label in tab or status bar; Insert mode is entered and typing is silently dropped. (27)
- **N10 No GUI way back after LSP trust "Not now"**: the Problems panel only says "folder not trusted", the status item "untrusted" opens Problems, Settings → Problems has no trust action; only `hutan lsp trust` or restarting the app (per-window memory). (81–83)
- **N5 Project replace**: clicking *Replace* shows the replace field but keeps focus in the search field, so typed text overwrites the search term; the INSERT chip eats most of the narrow replace field (text shows ":ga"); replaced files that were not open open as new tabs. (90, 91, 93)
- **N8 Agent bar names the chat's *first* prompt** ("· Append the line '// haiku e2e3' at the end of src/main.r…") although this edit came from a later turn; after *Undo* of a rewind the composer keeps the "Hutan restored these files… Disregard the changes of that turn." note. (100, 104)
- **N3 Chat's first Haiku edit failed** ("No file contents were reported for this change", OMP's edit needs a prior read) — OMP behaviour, shown as a red "failed" card; the later read+edit worked.

**Polish**

- N6 `jk` mapping does not apply in the Settings search field (typed "abjk" stayed in Insert); `type_text` from the driver bypasses Vim mappings (use `press_key`) — harness limitation, not a Hutan bug. (62)
- N7 Vim pane focus after ⌃W h/l is visible only as a slightly brighter tab label. (68, 69)
- After closing a bottom-dock panel with ⌘W the dock stays as "Empty dock. Drag a panel here…", taking 1/3 of the window, until `ToggleBottomDock`. (84, 98)
