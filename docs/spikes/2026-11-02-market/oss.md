5. **Orchestrator.inc** (`OrchestratorInc/agent-orchestrator`, 14 k★, Apache-2.0, Go, desktop + iPhone/Android): a *project's main agent plans, starts a worker per worktree, "comes back only when something needs you"*; Kanban lanes *Working / Needs you / In review / Ready to merge*; CI/review feedback routed back to the owning worker. Two **high-severity advisories** (unauthenticated loopback RCE; unauthenticated mobile-enable endpoint returning the connection password) filed 2026-10-14. [README](https://github.com/OrchestratorInc/agent-orchestrator), [#6687](https://github.com/OrchestratorInc/agent-orchestrator/issues/6687), [#6689](https://github.com/OrchestratorInc/agent-orchestrator/issues/6689)
6. **OSC 7501 "Program Status Protocol"** (Mitchell Hashimoto, 2026-10-06) is becoming the shared agent-state channel: libghostty-vt merged it the same day, Orca reads it (v1.4.232, 2026-10-20), Rex/Harness/tuios document it; herdr closed the request (screen manifests + socket). Hutan already parses it but **does not answer the `OSC 7501;?` feature query** (grep, see §6). [post](https://mitchellh.com/writing/program-status-osc7501), [spec](https://www.superlogical.com/rex/docs/build/program-status), [Ghostty PR](https://github.com/ghostty-org/ghostty/pull/14560)
7. **cmux RFCs for an agents view (#15266) and a name-addressed agent message bus (#15267)** (2026-09-28) written by cmux itself for "20–30 agents at once"; they state the design rules Hutan should copy for Mawas→agent messaging (queue by default, never interrupt a running tool, interrupt is a separate verb, a received message is data, not consent). [#15266](https://github.com/manaflow-ai/cmux/issues/15266), [#15267](https://github.com/manaflow-ai/cmux/issues/15267)
8. **Vibe Kanban sunsetting**: bloop shut down 2026-04-10, project "community maintained"; last tagged release 2026-04-24, repo still pushed 2026-10-29. Its issue tracker is now mostly stale feature asks. [post](https://www.vibekanban.com/blog/shutdown)
9. **Agent state detection is still the #1 reliability complaint** (herdr idle-vs-blocked, cmux flaky "Running/Needs Input", Orca false attention) — all of it caused by screen/title heuristics (§3.1, §6).
10. **Terminal-input injection between agents is the #1 messaging complaint** (Orca #19546, #22034, #17066; Omnigent #4682 model refuses wake notice as prompt injection) (§3.4).

**Supervision features since 2026-10-21** (all from [release notes](https://github.com/stablyai/orca/releases)):
- v1.4.246 (11-02) Orchestrator V3 "a lot more token efficient and reliable": coordinators end the turn and are woken by worker reports; shorter `check`/inbox output; give finished workers follow-ups, reopen closed workers; child agents collapsed, idle agents grouped on desktop+phone; Chat UI out of experimental; usage-limited chats can **continue with another account or agent harness**; phone Home "focused on what needs you"; "resolve conflicts and complete merges on desktop or phone"; plugin panels isolated in separate processes, warn before trusting non-official plugins.

## 3. Cross-project themes (what users ask for and complain about)

### 3.1 Attention / agent state (the loudest category)
- Heuristics fail in *both* directions and across versions: cmux [#1027](https://github.com/manaflow-ai/cmux/issues/1027) (+45, open 8 months), herdr [#4573](https://github.com/herdrdev/herdr/issues/4573)/[#3871](https://github.com/herdrdev/herdr/issues/3871)/[#4511](https://github.com/herdrdev/herdr/issues/4511)/[#5004](https://github.com/herdrdev/herdr/issues/5004), Orca [#13600](https://github.com/stablyai/orca/issues/13600), Omnigent [#8874](https://github.com/omnigent-ai/omnigent/issues/8874), Agent Deck 1.16.25 fix.
- **Background subagent/workflow = still working** is a repeated bug class (herdr #4511/#5004, cmux #20346, Agent Deck #2473/1.16.25, Nimbalyst #1269).
- Users want a **queue/drain**: Orca [#12577](https://github.com/stablyai/orca/issues/12577) next-needing-input hotkey; cmux RFC #15266 "who needs me?" one row per agent; agentbox "inbox"; Orchestrator.inc lane "Needs you".
- Only the **agent itself knows its state**: OSC 7501 (§6), Orca #26809, herdr #5069, herdr #4732 (labels must be scoped to a process).

### 3.2 Notifications
- Noise: one alert per worker (Orca #15148), every client plays the sound (herdr [#4787](https://github.com/herdrdev/herdr/issues/4787)), push when you're at the terminal (Happy [#1918](https://github.com/slopus/happy/issues/1918)), approval auto-answered by the client but chime still fires (Paradev #8762), "request user attention" steals focus (cmux #10770, #10325), mute per workspace (Orca [#28312](https://github.com/stablyai/orca/issues/28312)).
- Shipped answers: urgent/info tiers + digest + outbox (Agent Deck 1.16.25), acknowledged-stay-dismissed (cmux), worker heartbeat knobs (Orca 1.4.243).

### 3.3 Review / merge loop
- Feedback must go to **the same session** that wrote the code (Paradev [#8721](https://github.com/ParadevAI/Paradev/issues/8721); Orchestrator.inc routes CI/review to the owning worker; Claude Squad #328 CI verdict in list). Emdash [#1635](https://github.com/generalaction/emdash/issues/1635) diff since last turn; Paradev ships per-turn changes card + Undo (2.0.3); Orca resolves conflicts on phone. Orchestrator.inc has a reviewer agent that "can read every PR before a person does" and users already hit [#5701](https://github.com/OrchestratorInc/agent-orchestrator/issues/5701) (loops).

### 3.4 Cross-agent messages
- Delivery by **keystroke injection** is the defect source: lost when a modal is open, mixed into the operator's draft, lands unsubmitted (Orca #22034, #19546, #17066, #22651; cmux #15267 "a note typed into a pane where a person is half-way through an answer is appended to their draft"). Omnigent #4682: a wake notice on the *user* channel is refused as injection by a safety-tuned Claude.
- Converging design (cmux RFC prior-art table, 2026-09-28): queue by default; never interrupt a running tool; interrupt a separate verb; address by human name; a received message is data, not consent; deliver through the agent's own input path (Claude Code cross-session messages, Codex `turn/steer`, pi `steer`/`follow_up`, OpenCode `prompt_async`, A2A, ACP).
- Agent Deck tags every send with its sender and returns replies to the sender's inbox; Maestro `@agent` consults are single-turn and read-only unless you grant write; Reason Network/Omnigent A2A extend to teammates/remote agents.

## 4. Patterns across projects
1. **"Inbox" is now table stakes** — Herdr, cmux, Agent Deck (named by Mitchell as "agentic inbox"), Orca, agentbox, Orchestrator.inc, Paradev all converge on *one list of agents grouped by what they need from you*. Differentiation moved to *accuracy* and *what you can do from the row*.
2. **The supervisor-agent idea is arriving everywhere in four forms**: (a) coordinator that dispatches workers (Orca, Orchestrator.inc, Paradev skill, Omnigent), (b) *watcher* that answers prompts by rule (Pianola), (c) *conductor* that auto-responds when confident and escalates, with chat-ops (Agent Deck), (d) home "Chief" chat (cmux NEXT, unverified). Only Pianola documents hard safety rules + audit-before-dispatch.
3. **State comes from the agent or it is wrong**: OSC 7501 + hooks beat manifests; protocols (OSC 7501, A2A/ACP, OSC 9999 Orca, OSC 21337 iTerm2) are racing.
4. **Messaging moves from keystrokes to structured mailboxes** with ids, ack, tags and audit (Orca Run inbox, Agent Deck inbox/ledger, cmux bus RFC).
5. **Cost visibility ≠ cost control**: many dashboards, few caps; users are scheduling around *quota windows* (failover, pause-resume).
6. **Consolidation and churn**: Vibe Kanban sunset; Terragon shut; Crystal→Nimbalyst; Superset→Paradev; Mux→Xum; Omnara pivot; licence tightening (Paradev ELv2; cmux GPL + paid Cloud). VC money goes to *cloud/mobile/teams* (Paradev $11.5 M; cmux Cloud plans).
7. **Mobile and remote are monetised surfaces** (Paradev iOS = Pro; cmux Cloud; Orca free). Self-hosting/BYO-relay is the repeated user counter-ask.
8. **Maintainer-bot issue trackers** (Xum, Orca, Paradev triage prompts, Maestro, Agent Deck) mean raw issue counts overstate user demand; reaction counts are the useful signal (the top Orca/cmux asks are still *multi-repo*, *Linux/Windows*, *status reliability*).

## 6. OSC 7501 facts (for Hutan's terminal/agent-status work)
- Published 2026-10-06 ([post](https://mitchellh.com/writing/program-status-osc7501), [spec](https://www.superlogical.com/rex/docs/build/program-status)); libghostty-vt implementation merged 2026-10-06 ([PR #14560](https://github.com/ghostty-org/ghostty/pull/14560)); author reports proof-of-concept patches for Terraform, Claude Code, Codex, Homebrew ("no more than a dozen lines"); adopters/documenters: Rex, [Harness docs](https://harnesscli.dev/docs/program-status), [tuios](https://tuios.dev/docs/program-status), Orca (v1.4.232), OpenAgents proposal ([doc](https://github.com/OpenAgentsInc/openagents/blob/main/docs/terminal/program-status-osc7501.md)). herdr declined for now ([#5069](https://github.com/herdrdev/herdr/issues/5069)).
- Spec points beyond what `docs/integrations.md` says Hutan implements: `OSC 7501 ; ?` feature-detect reply; hierarchical `id` records with parent clear; `progress` 0–100; `kind` ∈ permission|question|auth; no heartbeat — `working`/`blocked` dropped on process exit or next OSC 133 `A`, `done`/`error` survive; ≤4096-byte sequence, 256 records/terminal (min 64), `msg` 2048 decoded; must refuse control characters in decoded text; label the source terminal in any UI; rate-limit anything caused outside the terminal. Spec explicitly says OSC 21337 (iTerm2) and OSC 9999 (Orca) are "not aligned".
- Orca's own issue ([#26809](https://github.com/stablyai/orca/issues/26809)) lists the cost of heuristics: per-agent title parsers in `src/shared/agent-title-*.ts` that "break whenever an agent changes its title format".
