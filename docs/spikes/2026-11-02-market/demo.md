# Market research — stream `demo`: how multi-agent supervision gets demoed

Researched 2026-11-02 (today). Window prioritised: 2026-08 → 2026-11; older anchors (Codex app Feb, Cursor 3 Apr, agent view May) kept as baselines because they set the genre. Every claim is linked; anything not read is marked `[INFERENCE]`.

**Limits of this pass (read first).**
- I read video *metadata and transcripts where YouTube served them* (length, upload date, views, chapters, description). I could not watch pixels. Where a video has no transcript, the scenario comes from its description/launch post and is marked so.
- X/Twitter and Reddit blocked automated reads ([X](https://x.com/cognition/status/2113671026286682500), [Reddit](https://www.reddit.com/r/ClaudeAI/comments/1x446nm/projects_is_the_biggest_claude_code_update_this/)); YouTube comment sections were not served. "Reception" below therefore = Hacker News threads, vendor forums, press, and view counts. View counts are as shown on the video page on 2026-11-02.
- Hutan facts come from `CHANGELOG.md` (0.3.5 2026-10-31, 0.3.4, 0.3.2, 0.3.0), `docs/assistant.md`, `docs/vision.md`, `docs/spikes/2026-10-30-mawas-supervisor.md`.

## 2. Patterns

### What lands
1. **One loop, one sentence: dispatch → leave → return to a ready list.** Agent view's whole 39-second pitch is "kick off… jump in only when Claude needs you… return to a list of pull requests ready for review" ([post](https://claude.com/resources/articles/agent-view-in-claude-code)); Devin: "I left for a haircut… The agents kept working" ([row 10](https://www.youtube.com/watch?v=zIl6h7Z60PI)); Warp: "come back in the morning" ([row 5](https://www.youtube.com/watch?v=RWT3sh68PWE)). *Leaving* is the wow; *watching* is not.
2. **Short official cuts, long founder cuts.** Official launch clips are 0:26–2:17 ([Projects clip](https://www.youtube.com/watch?v=-EAEc4LiTyo) 0:26, [agent view](https://www.youtube.com/watch?v=-INveHwbRz4) 0:39, [Cursor 3](https://www.youtube.com/watch?v=UxbULt_hCdA) 1:30, [Codex](https://www.youtube.com/watch?v=0e-Brv-gS9Q) 2:13, [Warp](https://www.youtube.com/watch?v=RWT3sh68PWE) 2:17); the 2–5 min guide is where depth lives ([Projects guide](https://www.youtube.com/watch?v=omihvjf0A2k) 4:33 · 391K); 11–18 min is founders/conference only ([Conductor](https://www.youtube.com/watch?v=fQmlML9Lay4) 16:35, [talk](https://www.youtube.com/watch?v=TRfzFJCJ7ZE) 17:44).
3. **A real mistake caught by the human.** The Codex multitasking video's best second is the reviewer noticing "it's creating the branch twice" and commenting on the diff ([transcript](https://www.youtube.com/watch?v=9ohXlkbXiM4)). Devin's math video keeps "the full, unedited process" ([desc](https://www.youtube.com/watch?v=zIl6h7Z60PI)). Honest friction reads as trust `[INFERENCE: no comment sections read]`.
4. **Counts as the wow**: "100+ parallel Devins", "40-50 agent sessions" ([HN](https://news.ycombinator.com/item?id=48236770)), "1,024 agents with no boss" ([Microsoft Agensh write-up](https://byteiota.com/microsoft-agensh-1024-agents-no-orchestrator)). Numbers are cheap to show; the count is the hook, not the supervision.
5. **Phone → cloud → desktop handoff** appears in 6 of 13: Cursor 3, Warp, GitHub Universe, Conductor talk, Superset (mobile coming), Antigravity ("Remote Control" announced) ([sources above](#1a-demos-with-video-metadata-read)). It is the 2026 "wow" for *continuity*; Hutan has no phone/cloud (remote hosts are experimental, [CHANGELOG 0.3.5 L46](../../../CHANGELOG.md)) so we cannot compete on it.
6. **Artifacts as proof**: Cursor's "demos and screenshots of their work for you to verify" ([blog](https://cursor.com/blog/cursor-3)), Devin's Lean proofs ("If it doesn't compile, it doesn't count", [desc](https://www.youtube.com/watch?v=zIl6h7Z60PI)). The supervisor wow is *verification*, not volume.
7. **A positioning sentence that names an enemy**: "nobody likes micromanaging agents" ([GitHub](https://www.youtube.com/watch?v=xbCa0aa4tRM)), "I honestly kind of hate the term 'software factory'" ([Conductor](https://www.youtube.com/watch?v=TRfzFJCJ7ZE)), "from folder to conversation" ([Anthropic](https://claude.com/blog/projects-redesigned)).

### What falls flat or gets mocked
1. **Forcing the paradigm.** Cursor 3's top HN comment and forum rejections ("zero interest in… swarms", "I can only sit at one granularity level") ([HN](https://news.ycombinator.com/item?id=47618084), [forum](https://forum.cursor.com/t/cursor-3-agents-window/156509)). Users want to drop to the transcript/diff at will.
2. **Hidden cost of the supervisor itself.** The 586-pt HN thread on background-agent transcripts being sent to the model for labels ([HN](https://news.ycombinator.com/item?id=50284255)) and Cursor cloud bills ([dev.to](https://dev.to/onepizzateam/cursor-3-shipped-parallel-agents-and-the-community-cant-agree-on-whether-thats-good-1p3n)). A supervisor that silently burns tokens is mocked harder than a dumb one.
3. **Launch-day "can't find it / stuck loading / 2GB".** Cursor 3 forum (feature invisible until sign-out/in), Codex "Loading projects…", Superset "2GB!… freezing" ([HN](https://news.ycombinator.com/item?id=46859054), [HN](https://news.ycombinator.com/item?id=48236770)). A staged demo on an unreleased build invites this.
4. **Electron/"native" pile-on** around OpenAI's app ([HN](https://news.ycombinator.com/item?id=46859054)) — Hutan's native GPUI is a non-feature to show but a free tailwind to *mention once*.
5. **Gating**: waitlist/beta for Projects ([blog](https://claude.com/blog/projects-redesigned)), Duet signup complaints ([HN](https://news.ycombinator.com/item?id=50186037)). Hutan is a downloadable pre-release ([CHANGELOG L191](../../../CHANGELOG.md)) — say "brew install" on the last frame.
6. **"Factory / control plane / fleet" vocabulary** — fatigue shows in the Offrun thread ("meta-orchestrator for all these agent orchestrators", [HN](https://news.ycombinator.com/item?id=49942434)) and Holtz's rejection of "factory" ([talk](https://www.youtube.com/watch?v=TRfzFJCJ7ZE)). Enterprise decks ([Warp](https://www.warp.dev/blog/the-factory-stack)) are a different buyer than Hutan's.
7. **One-shot "async agent writes a PR" as a product.** Jules is being wound down ([changelog](https://jules.google/docs/changelog/)); Vibe Kanban sunset ([blog](https://www.vibekanban.com/blog/shutdown)).
8. **Great craft, no distribution**: Devin's two best orchestration videos have 526 and 681 views ([row 10](https://www.youtube.com/watch?v=zIl6h7Z60PI), [row 12](https://www.youtube.com/watch?v=XqtNS-LU-b8)) vs 3.1M for Cursor's 1:30 — a demo does not substitute for a launch channel.

### The gap (what *nobody* demoed)
Every supervisor demo above shows a manager that **does** things (delegate, merge, route, schedule): Projects' coordinator ([blog](https://claude.com/blog/projects-redesigned)), Devin's master session ([row 10](https://www.youtube.com/watch?v=zIl6h7Z60PI)), Copilot Projects ([GitHub](https://www.youtube.com/watch?v=xbCa0aa4tRM)), Oz/Factories foreman ([Warp](https://docs.warp.dev/factories/how-factories-work/)). None demonstrated: *what the supervisor does not know* (coverage), *a suggestion that is not an answer*, or *a per-agent approval of a message to another agent*. That is Hutan's demoable difference: **a supervisor you can trust because it says where each fact comes from and never answers for you** — and the HN signal that people want exactly this (the 90% orchestrator comment, row 1b; the hidden-token-burn thread, pattern 2).

## 4. Proposed Hutan demo — "Three agents, one that waits for you" (target 2:30, hard max 3:00)

Everything below uses only features in `CHANGELOG.md` 0.3.5/0.3.4 (+ earlier releases where noted) and `docs/assistant.md`. Line cites are CHANGELOG line numbers as read 2026-11-02. Install state: a 0.3.5 pre-release build ([L42](../../../CHANGELOG.md)).

### 4.1 Set (stage this before recording)

- **Fresh `HUTAN_HOME`** and a clean macOS user/desktop (briefs' convention: "Fresh `HUTAN_HOME`", e.g. `docs/briefs/AGENTS-ACTIVITY.md`). Dark theme, one window ≈ 1440×900, large UI size, hide Dock/menu-bar clutter. Settings → Status bar → *Usage limits* → hidden (rings only show once an agent reports a limit; [0.3.2 L77](../../../CHANGELOG.md)).

  - **A** — Codex *chat* on the Rust repo, in a **new worktree** (structured → journal → rows say *exact*; worktrees/Changes: [0.3.0 L124–L125](../../../CHANGELOG.md)).

  - **C** — OMP in a **terminal** on the Python repo, recognised by its glyph/spinner/bell ([0.3.2 L73](../../../CHANGELOG.md)) → *state only* (the coverage label the demo wants to show).
- **Mawas**: Global chat (default Home, [L24](../../../CHANGELOG.md)), backend = Claude Code or OMP, mode *Ask before acting* (default, `docs/assistant.md` § Modes), `assistant.web` left **off** (default, [L33](../../../CHANGELOG.md)).   - A: "Add `--version` to the CLI and update the README." (no approval needed; should finish → *Ready for review* because files changed, [0.3.0 L138](../../../CHANGELOG.md)).

Used only as the *state only* example in scenes 1–2.
  - To get the "failed command" sign for scene 4: seed one failing test on the fork's branch so A's or B's first test run exits non-zero. (Needed for the *done after a failed command* warning; [L17](../../../CHANGELOG.md).)
- **Capture**: screen recording at 60 fps with a visible cursor; zero live typing except Mawas prompts, which are pasted from a text file. Keep a 2nd take armed (see risks).

### 4.4 Risks and how to defuse them

| ID | Risk | Mitigation |
|---|---|---|
| R1 | **Model nondeterminism**: agents may not wait/fail where scripted. | Start agents 3–6 min early and *check state before pressing record*; keep 3 pre-started "arms" and pick the best take; record scenes separately and cut together (always labelled `+N s` for jump cuts). |
| R2 | **Mawas's wording varies** (may omit source/coverage, call something idle). | The playbook asks for sources and coverage ([L15](../../../CHANGELOG.md)), but it's a prompt. Run the exact prompt 5× beforehand; if she drifts, re-take. Do not edit her text. |
| R3 | **`ask.suggest` isn't automatic**: she may not attach a suggestion, and the call itself asks for permission (`docs/assistant.md` § Suggested answers). | Prompt says "attach your suggestion"; show the permission card as part of the scene (it *is* the safety story); pre-test twice. |
| R4 | **Scene 5 target rule**: she "cannot type into an agent that waits on a prompt" and messages never go into an agent waiting on an answer ([L25](../../../CHANGELOG.md)). | Nudge agent A (not waiting). Don't try to "tell B/C" while they wait — it would correctly be refused (could be a *good* 5 s outtake: the refusal card). |
| R5 | **Flow/Recent need history** and say what isn't recorded ("not recorded", never zero, [L14](../../../CHANGELOG.md)). Terminal-agent waits count only from when the 14-day state log began ([L16](../../../CHANGELOG.md)). | Pre-run the agents for a day or two before shooting; on camera, read the coverage note aloud — it *is* the differentiator. |
| R6 | **Mawas startup latency** (harness assistant starts asleep, ~460 MB OMP process, `docs/assistant.md` § Idle assistants). | Warm her chat before recording; use a `+6 s` caption; keep the first prompt short. |
| R7 | **Pre-release build instability**: 0.3.5 is two days old and a pre-release ([L42](../../../CHANGELOG.md)); the DB schema migration is forward-only ([L45](../../../CHANGELOG.md)). | Record on a copy of the data dir; do a full dry run on the exact build the day before; never update mid-shoot (in-app update prompts show in the status bar, [0.3.3 L62](../../../CHANGELOG.md)). |
| R8 | **Secrets/PII on screen**: agents print env, account names; usage rings, account names (multiple accounts, [0.3.0 L126](../../../CHANGELOG.md)). | Demo accounts only; scrub the take; Mawas's own redaction doesn't cover your screen. |
| R9 | **Public-repo hygiene**: agents push/PR. | Forks under a demo account; no remote on the Rust repo checkout, or `Finish` without remote commits only ([0.3.0 L117](../../../CHANGELOG.md) describes Finish without a remote). |
| R10 | **Honesty**: competitors' staged heroes ([Paradev](https://paradev.com/)) draw no mockery *because* the genre allows it, but our whole pitch is truthfulness. | Real agents, real states; say "sped up" when sped up; no fixture agents in the hero take. A disclosed `[cut for time]` costs nothing; a fake costs the thesis. |
| R11 | **Comparison temptation**: naming Claude Projects/Codex/Cursor invites fact-checks. | Don't name them in the video. If asked in comments: coordinators that *do* (Projects) vs a supervisor that *reports and asks*; cite [Projects blog](https://claude.com/blog/projects-redesigned) ("limits you give it are instructions… not enforced" per the spike §2.9). |

### 4.5 Voice and copy rules (from what landed / flopped)
- Say *"waiting on me"*, *"needs me"*, *"she suggests, I answer"*. Avoid *fleet, swarm, factory, orchestrate, control plane* (pattern 6).
- Put the honesty claim on screen as text, not only voice: "state only", "not recorded", "from Mawas · sent with your approval".
- One sentence on privacy/cost: "the board and catch-up use no model" (answers the token-burn thread, pattern 2).
- Don't promise PRs, cloud, phone. The last frame is the install line and "pre-release".
